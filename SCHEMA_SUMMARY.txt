  ✓ Admins can read all users

courses:
  ✓ All authenticated users can read
  ✓ Only admins can create/update/delete

enrollments:
  ✓ Students can read own enrollments

TYPICAL DATA FLOW
─────────────────

1. User Registration → insert into users, create student_profiles if student
2. Course Creation → admin inserts into courses
3. Enrollment Request → student inserts into enrollments (status: pending)
4. Admin Approval → admin updates enrollments (status: approved, approved_by)
5. Add Materials → admin inserts into course_materials
6. View Materials → student sees materials (enrolled + approved)
7. Grade Assignment → admin inserts into grades
8. Notifications → auto-created for enrollment changes, grade updates
